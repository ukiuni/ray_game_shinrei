# 心霊記録室

100枚の生成心霊写真から、1枚につきひとつの心霊を探す日本語ブラウザゲーム。Android Chrome、iPhone / iPad Safari向けの固定ビューポートとPWAに対応しています。

## 遊び方

「探索をはじめる」を押し、写真の心霊がいる場所をタップしてください。正解は○と「正解」のオーバーレイを表示し、1.35秒後に自動で次の写真へ進みます。不正解はタップした場所に×を表示します。1枚30秒、間違いは探索全体で3回まで。敗北時には正解位置を示します。100枚すべて見つけると完全クリアです。写真の順番は探索ごとにランダムで、同じ探索では重複しません。最高連勝記録は端末内に保存します。

キーボードでは写真にフォーカス後、矢印キーで照準を動かし、EnterまたはSpaceで決定できます。効果音は初期状態でオフです。

## ローカル実行とテスト

Node.js 22以上を使用します。

```sh
npm ci
npm run build
npm run dev
```

http://localhost:4173 を開いてください。

```sh
npx playwright install chromium webkit
npm test
```

Android相当のChromium、iPhone・iPad相当のWebKitで、正誤判定、自動継続、敗北、時間切れ、100枚完走、オフライン動作を検証します。これは端末エミュレーションであり、実機検証とは異なります。

## GitHub Pages

`.github/workflows/pages.yml` はmainへのpush時にビルド・ブラウザテストを行い、成功した成果物をGitHub Pagesへ公開します。リポジトリのSettings → Pages → Sourceは「GitHub Actions」を使用してください（workflowでも有効化を試みます）。公開URLは `https://ukiuni.github.io/ray_game_shinrei/` です。相対パスを使用しているため、リポジトリ配下の公開に対応しています。

## PWAと更新

HTTPSまたはlocalhostでService Workerが動作します。初回は100枚すべてとアプリをキャッシュします。初回キャッシュが完了した後はオフラインでも遊べます。Androidではブラウザのインストール操作、iPhone・iPadではSafariの共有 → ホーム画面に追加を使います。

起動時、画面に戻った時、通信復旧時、および5分ごとに更新を確認します。新バージョンのダウンロードはバックグラウンドで行い、探索中・正解演出中・次画像読み込み中・敗北時の正解表示中は適用を保留します。ホームか結果画面になった時点で適用して再読み込みします。ファイル内容からキャッシュバージョンを生成するため、変更があるビルドだけ新しいキャッシュになります。

## 画像と判定データ

`public/photos/` の100枚はこのゲーム向けに生成した架空の心霊写真です。実際の心霊現象の記録ではありません。`public/photos.json` に画像ごとの正解領域を正規化座標（中心x/y、楕円半径rx/ry）で保持しています。画像の表示寸法にかかわらず同じ場所を判定します。
